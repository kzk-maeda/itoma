# MVP仕様

状態: **提案・未確定**。検討Issue: https://github.com/kzk-maeda/itoma/issues/21。この文書は実装・OS動作の保証ではありません。


## 確定した制約

iOSのみ、React Native + TypeScript、OS連携はSwift、Local-first。バックエンド・独自認証・Android・実課金は対象外。本人の選択と明確な取消を守り、滞在時間を増やすUIにしない。

## 利用シナリオの初期案

| 場面 | 利用者の目的 | 期待する結果 | 未決定・検証 |
| --- | --- | --- | --- |
| 初回 | 制限の意味を理解して対象を選ぶ | 認可と対象選択を明確に分離。拒否しても戻れる | 認可要求のタイミング |
| 設定 | 対象・時間帯・解除条件を自分で決める | 確定前の取消で元の設定を保持 | 初版の時間帯・モード数 |
| 制限中 | 現在何が適用されているか知る | 希望設定と確認済み適用を区別 | OS状態の観測範囲 |
| 一時解除 | 条件を理解して利用するか決める | 期間と再制限の条件を選択前に理解 | 導線・期間・待機・回数 |
| 権限取消・障害 | 原因と次の操作を知る | 確認できない制限を有効と表示しない | 復旧と安全側の挙動 |

## 初版範囲の決定表

| 候補 | 現在の扱い | 判断に必要な証拠 |
| --- | --- | --- |
| 手動ブロック・解除 | 最小実機PoC候補 | 本人が選んだ対象で適用・解除成功 |
| 曜日・時間帯 | MVP候補、未決定 | 日跨ぎ・競合の仕様とOSイベントPoC |
| 一時解除・期限後再制限 | MVP候補、保証未確認 | JS停止中の期限処理の実機結果 |
| 3段階モード・履歴 | 後続候補、初版採否未決定 | 効果より先に操作理解と取得可能データを確認 |
| 仮想課金 | 実験候補 | 実決済と誤認しない説明。別の仕様決定 |

5分、待機秒数、回数上限、価格、モード名称は確定値にしません。対象アプリ内部の画面限定制限や全アプリ起動の取得を約束しません。

## 決定時に埋める項目

初版に含む/含まない機能、各シナリオの受入条件、未実施PoC、設計Issue/ADR/決定PR、残る検証条件。これらがレビューされるまではUIのサンプルモードを製品仕様と扱いません。
