# 0007: 一時解除を除いた制限時間を振り返る案

- 状態: **Proposed**。本人の計上方針を反映し、観測/保存/削除の詳細をレビュー中
- 検討Issue: https://github.com/kzk-maeda/itoma/issues/96
- 後続: #97 / #98 / #99 / #100。操作履歴は #57 / #132
- 根拠: #86/PR88と#17の固定累計＋週次/月次UI、本人の「実際にアプリを制限して自分の時間を過ごせた時間」「一時解除時間は累計に含めない」という最新指示。デモ用の解除非控除の数値定義は製品へ採用しない

## 提案

記録したpolicy/Activation/contextと、nativeの適用/解除/再制限の確認から、制限を続けた区間を求める。重複時間は1度、未来を除き、**一時解除の区間を除外する**。停止/未適用/失敗/不明/欠損も加算せず、予定期限だけで再制限成功としない。累計/週/月/日で同じ規則を使う。記録開始前や欠損を既知0と区別し、未記録の過去を埋めない。

21〜23時に5分の解除を確認した例は115分、2分で早期終了して再制限を確認した例は118分。本人の自分の時間の積み重ねを穏やかに伝え、解除を減点/失敗と評価しない。何に時間を使ったかを推定/採点しない。own-storeの操作確認と、OS全体で連続遮断できた証明の限界を区別し、根拠のない時間はpartialとして計上しない。

private ledger/read revisionと固定as-ofから、上部の全記録累計と選択週/月の有界DTOを同じtokenで返す。理由・操作履歴の既存削除は累計を消す意味へ変えず、累計も消す新しい明示操作を分ける。

詳細・代替案・例・timezone/時計変更の限界・migration/coverage/cutoffの採用条件は [契約案](../system/time-reflection-contract.md)。

## 採否と検証

一時解除を含めない計上方針は本人が指定済みであり、同じ質問を再度求めない。ADR全体をAcceptedへ変更する際は、その他の詳細を人間がレビューした範囲と決定PRのmain反映を記録する。独立agent review/文書CIや今回の指示から全条項の一括採用を推測しない。新しい記録のiOS実機成立、App Groups/File Protection、実プロセス停止/再起動は別に検証する。
