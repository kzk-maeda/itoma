# いとまを支える

設定の末尾から、開発者の手紙を読み、今回だけ・毎月の任意の金額を選びます。100・300・500円は日本向けの比較用の例です。単発が初期表示で、金額の初期選択はありません。Webデモの選択はメモリ内のみ。実請求、支援者だけの解除や記録機能、外部への送金はありません。

購入確認で見送るか、模擬支援を確定して設定へ戻れます。毎月の支援は、同じ入口から設定中の金額を確認し、次回の更新を停止できます。毎月はスポンサー体験の仮説で、App Storeの自動更新商品として承認済みの仕様ではありません。

## iPhoneの日本ストア向けに検討する際の前提

- 開発者へのチップにアプリ内購入を使う方法はガイドライン3.1.1に明記されています。初版は単発の消耗型IAPが候補です。
- 3.2.1(vii)のIAP不要の贈与は、個人間・完全に任意・受取人に100%が渡る場合で、デジタルコンテンツやサービスの対価を伴うとIAPが必要です。開発者自身の運営支援に適用できるかは個別判断です。
- 毎月の自動更新には3.1.2(a)の継続的価値の要件があります。運営へのお礼だけで成立する前提は置きません。
- 日本のiOS 26.2以降のiPhoneでデジタル商品・サービスの別決済や外部購入リンクをアプリ内に出す場合は、対象契約・エンタイトルメント、IAPの同時提示、告知・報告などが必要です。アプリ外で独立して行う案内とは条件が異なります。
