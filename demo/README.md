# 振り返りの累計を、累積グラフで見せる比較デモ

2026-11-20 JST / #254。本人のスクリーンショットで、累計カード内の点列が区間ごとの増減を描き、日付・単位もなく意味が伝わらなかった。今回の本人指定は、このカードを「時間がどう積み上がったか」にすること。

## 表示の契約

- 上段は記録開始から確認時点までの累計。一時解除を除いた架空の制限時間を、日ごとに足した線と控えめな面で示す。
- 累計の数字とグラフの最終点は同じデータ・範囲。横に日付、縦に累計時間（時間単位）の目盛り。「累計の推移」「日ごとの記録を足し合わせています」を添える。
- 下段は選んだ週/月だけの合計と内訳。週/月・過去の期間に移動しても、上の数字・線・対象範囲を変えない。週と月の閲覧位置はそれぞれ保持する。
- 欠測を0秒にしない。一部未記録なら、その前後で線/面を切り、判明している記録の累計と明記する。欠測期間への直線補完は行わない。
- 未記録は「—」＋記録がない旨、既知の0分は「0分」＋0の水平線で区別する。
- 日々の振り返りを採点せず、連続達成・ランク・祝福・利用を煽る演出は加えない。累計は同一の固定データ内で非減少だが、削除/再集計/時刻変更を跨いで絶対に減らない保証はしない。

原則1/3/4、U07、UI22〜UI25、振り返り契約RF01/RF05/RF09に関連。固定累計と期間別内訳を区別する既存の設計を維持する。

全て固定の合成値。実OSの制限・遮断成功、利用実績、保存・取込は使わない。架空データはUTCの日付キーで組み立て、アプリのルール/DST評価器を複製するものではない。期間内の無イベント日も明示的な既知0として生成した長期fixtureであり、実データの欠損を0へ変換する処理ではない。

## 本体との境界

差分はdemo/のみ。独立Expo Web入口・専用Router・fixture・UI状態を所有し、本体のBody/Button/useFlowTheme、Graphite/HomeLayout、ProductNavigation、PeriodSelector/PeriodTransition、OpenCircle、reflectionDurationと型を一方向に参照する。本体のReflectionContent/Trendや集計API、Swift/保存は変更しない。モジュールの差替えやグローバル時計・Alertの上書きはない。

ホームはこの比較への入口、設定は比較範囲の案内。製品のホーム/設定そのものの再現ではない。期間の各行から日別履歴へ進む本体の体験は今回の比較範囲に含めず、押せるふりをしない。上部の「切替」はデモ操作。更新操作も架空データの再表示のみ。
