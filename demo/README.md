# いとまの画面比較

main `281be275` の3場面を、同じ架空条件で比較する。「現行の要点」は判断に関連する表示の抜粋。各場面・表示を切り替えると初期状態へ戻る。時刻は22:57に固定。端末への保存・Screen Time操作は行わない。

| 入口 | mainでの観察 | 試す操作 |
| --- | --- | --- |
| / | 一時解除確認では対象・ルール・理由・時間が別パネル。実効上限は4枚目にある | 希望10分・上限3分を確認し、理由の編集、制限継続の破棄確認、一時解除の結果を試す |
| /home | 反映を確認できない時、ホームに設定タブを案内する文がある | スクリーンタイムへ直接進み、架空の再確認を実行してホームへ戻る |
| /schedules | 全体停止中も各ルールの保存設定は有効と表示され、全体状態は一覧の下 | 全体状態を確認し、再開確認を取り消す／確定する |

「スクリーンタイムで確認する」は遷移のみ。到着後に再確認・反映操作の内容を説明する。実機の照合失敗、再選択や再認可が必要なケースは今回の正常復旧シナリオ外。実装時は既存の状態判定・無効条件・取消と期限を維持する。

実装参照は src/components/flow/{unlock,home,settings}.tsx と src/components/home/rule-status-view.tsx。本体のPeriodRing、テーマ、Panel、Buttonを読み取り参照する。振り返りの提案は #266。ブランチのデプロイ先は npm run demo:info で確認できる。
