# 振り返りの可視化を比べるデモ

2026-11-21 JST / #256。累計グラフの比較デモ #255 を基に、時間をどう見せると読み取りやすいか、4案を操作して比べる。製品への採用は未決定。

## 画面と操作

| URL末尾 | 案 | 試せること |
| --- | --- | --- |
| `/blocks` | 時間のブロック | 1ブロックの単位と端数。下部の週/月・前後期間 |
| `/weeks` | 週ごとの積み上げ | 全体を構成する週を1本の帯で表示。週を選んで日別内訳を展開 |
| `/calendar` | カレンダー | 週/月と前後期間。日付選択→同じ日の時間帯へ |
| `/day` | 1日の時間帯 | 前日/翌日、24時間/記録した時間帯への拡大、カレンダーへ戻る |
| `/reflection` | 比較：累積グラフ | #255 の日付・時間目盛り付きの累積線 |

上部の「表示案を切り替える」で、同じデータを維持して案を変更する。ホームは5案の入口、設定は比較範囲の案内であり、製品ホーム/設定の再現ではない。データ選択と表示案選択は比較用の操作。

原則1/3/4、U07、UI22〜UI25、RF01/RF05/RF08/RF09に関連。記録を採点せず、目標達成率、空の目標ブロック、連続達成やランクは加えない。色に加え数字・日付・単位・選択線・代替文で伝える。

## 数字の意味

- 上段は記録全体の累計。下段で週/月/日を動かしても上段の範囲は変えない。
- 全案で同じ架空の日別データと `reflectionDuration` を参照。一時解除を除く制限時間で統一。
- 初期値は11/2〜11/20の3週間、累計4時間13分。週の内訳は25分/45分/3時間3分。週次の初期値は11/16からの週。
- ブロックは通常1時間単位、4個と13分の端数。大きな累計では12個以内になる単位へ変更し、必ず単位を記載。空の達成枠ではない。
- カレンダーは数字が分数、濃さは同じデータ内の時間の長さ。0分は既知の0、— と破線は未記録。固定確認日11/20より先は「未到来」で無効。
- 時間帯は日別の分数と整合する合成区間。正の記録は10分の一時解除を挟んだ2区間に分ける。制限区間の合計だけが日別時間となる。実際の開始時刻・解除履歴を日別合計から復元したものではない。
- 時間帯の塗り/破線/斜線と区間リストで、制限・一時解除・未記録を区別。0分と未記録を同じ空のバーにしない。
- 未記録は0秒へ変換しない。一部欠測は既知部分のみと明示。累積線は欠測前後で切り、補間しない。

## データ切替

| 名前 | 内容 |
| --- | --- |
| 複数週 | 上記3週間、4時間13分。その他の日は明示的に既知0 |
| 通常 | 11/16〜11/20の50/70/13/80/40分、4時間13分 |
| 一部の記録なし | 通常の11/18が未記録、既知累計4時間 |
| まだ記録なし | 空の記録。累計は— |
| 記録あり・0分 | 5日間が既知0分 |
| 長期間 | 9/1〜11/20の81日、85時間13分 |

日付キーはUTCで生成する固定fixture。実データの欠損を0へ変換する処理ではない。集計削除/再構築/時刻変更を跨ぐ累計の単調増加を保証しない。
