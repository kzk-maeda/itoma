# 一時解除の方法を選ぶデモ

[デモを開く](https://itoma-demo.kzk-maeda.com/demos/demo-unlock-choices-ffbe90ffbe07/)

「夜の読書」のルール設定から始まり、保存すると、ルール適用中の21:45を起点にしたホームに進む。X・YouTubeから一つを選んで一時解除を試せる。

| 一時解除の方法 | 設定するとき | 開きたくなったとき |
| --- | --- | --- |
| 理由を書いて開く | 初期選択。料金は無料 | 自分のことばで理由を入力し、対象と期限を確認して開く |
| 決めた額で開く | 1回分の金額を100・300・500円から選ぶ。金額の初期選択なし | 本人の目的と金額を振り返り、対象・期限を確認してから模擬購入へ進む。購入確定時のみ解除する |

名称は「強い／弱い」という自己評価を避け、開くための行為を同じ文型で表した。「ことばでひと呼吸／金額でひと呼吸」も候補だが、後者だけでは金額の確認と支払いを区別しにくいため、採用案では設定時に「解除するたびに支払います」と補っている。

料金候補と5分間の期限は比較用。ホームから「別の設定でデモを試す」で最初からやり直せる。入力・選択・解除状態はメモリ内でのみ扱う。実際の決済、アプリ起動、OSの制限変更は行わない。
